# 日期提醒通知設定說明

> 建立日期：2026-04-29
> 作者：Jimmy
> 功能：輸入日期與天數，到期當天自動推播 LINE 提醒

---

## 架構概覽

```
使用者開啟 date_reminder.html（本機瀏覽器）
    ↓ 填寫日期 + 天數 + 備註，按新增
GitHub API 寫入 reminders.json（yaojing277/stock-notify）
    ↓
cron-job.org 每天 09:00（Asia/Taipei）觸發
    ↓
GitHub Actions 執行 check_reminders.py
    ↓
比對今天日期 vs remind_on，命中則推播
    ↓
LINE Messaging API 推播到手機
    ↓
reminders.json 移除已發送的項目，自動 commit
```

| `reminders.json` | repo 根目錄 | 提醒資料儲存（自動維護） |

## 一、日常使用

### 新增提醒

1. 用瀏覽器開啟 `jimmy_scripts/date_reminder.html`
2. 填寫：
   - **起始日期**：提醒計算的起點
   - **幾天後提醒**：幾天後要收到 LINE
   - **備註**（選填）：提醒內容說明
3. 按「新增提醒」→ 頁面自動顯示「LINE 提醒日」
4. 資料立即寫入 GitHub，到期當天早上 09:00 收到 LINE

### 查看 / 刪除提醒

- 網頁下方列表會顯示所有未到期提醒與倒數天數
- 點「刪除」即從 GitHub 移除，不會再收到通知

## 二、GitHub 相關設定

### Repository

| 項目 | 內容 |
|------|------|
| Repo | [yaojing277/stock-notify](https://github.com/yaojing277/stock-notify) |
| 腳本 | `check_reminders.py` |
| Workflow | `.github/workflows/check_reminders.yml` |
| 資料檔 | `reminders.json` |

### GitHub PAT

網頁表單需要一個有 `repo` + `workflow` 權限的 PAT：

1. GitHub → 右上頭像 → Settings
2. 左側底部 → **Developer settings**
3. **Personal access tokens** → **Tokens (classic)**
4. **Generate new token (classic)**
5. 勾選 `repo`（整排）+ `workflow`
6. 產生後貼入網頁 Token 欄位，儲存在 localStorage

> ⚠️ Token 只顯示一次，請立刻複製貼上。
> ⚠️ 不要 Regenerate 舊 token，會造成 stock_notify cron-job.org 失效。

## 三、cron-job.org 排程設定

### 建立排程

| 欄位 | 值 |
|------|----|
| URL | `https://api.github.com/repos/yaojing277/stock-notify/actions/workflows/check_reminders.yml/dispatches` |
| Method | POST |
| Body | `{"ref": "main"}` |
| Timezone | Asia/Taipei |
| Cron | `0 9 * * *`（每天 09:00） |

### Headers

| Key | Value |
|-----|-------|
| `Authorization` | `Bearer ghp_你的token` |
| `Accept` | `application/vnd.github.v3+json` |
| `Content-Type` | `application/json` |

### 測試

設定完後點「**Perform test run**」，回應 `204 No Content` 表示成功。

## 六、注意事項

| 項目 | 說明 |
|------|------|
| 電腦不需開著 | 完全在 GitHub 雲端執行 |
| 推播後自動清除 | 到期的提醒推播後從 reminders.json 自動移除 |
| 時區 | GitHub Actions 以台灣時間（UTC+8）比對日期 |
| LINE 額度 | 每則提醒各消耗 1 則，免費方案 200 則/月 |
| LINE 金鑰 | `LINE_TOKEN`/`LINE_USER_ID` 存 GitHub Secrets（與 stock_notify 共用）；`check_reminders.py` 以 `os.environ` 讀取，程式碼無明文（2026-06-26 起，缺值即 `SystemExit`） |
