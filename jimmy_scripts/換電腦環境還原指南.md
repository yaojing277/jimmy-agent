# 換電腦環境還原指南

> 建立日期：2026-04-12
> 作者：Jimmy
> 用途：換新電腦時，依照此指南還原所有工具、指令與腳本

---

## 所有設定的存放位置

| 項目 | 存放位置 | 說明 |
|------|---------|------|
| 環境變數（LINE Token 等） | `yaojing277/dotfiles`（Private Repo） | `.zshrc` |
| 股價通知腳本 | `yaojing277/stock-notify`（GitHub Repo） | 雲端執行，換電腦不影響 |
| YouTube 通知腳本 | `yaojing277/stock-notify`（GitHub Repo） | 雲端執行，換電腦不影響 |
| Claude Code Skills | `yaojing277/dotfiles`（建議加入備份） | `/notify`、`/line`、`/stock` |
| 本機腳本與說明文件 | `jimmy_scripts/` 資料夾 | 建議定期備份至 dotfiles |

---

## 還原步驟

### 第一步：安裝必要工具

```bash
# 安裝 Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安裝 Python
brew install python

# 安裝 Claude Code
npm install -g @anthropic-ai/claude-code
```

### 第二步：還原環境變數（.zshrc）

```bash
# clone dotfiles
git clone https://github.com/yaojing277/dotfiles.git ~/dotfiles

# 複製到家目錄
cp ~/dotfiles/.zshrc ~/.zshrc

# 讓設定生效
source ~/.zshrc
```

### 第三步：還原 Claude Code Skills

```bash
# 建立資料夾
mkdir -p ~/.claude/commands

# 從 dotfiles 複製（若已備份）
cp ~/dotfiles/commands/*.md ~/.claude/commands/
```

> 若 Skills 未備份到 dotfiles，告訴 Claude Code「幫我重建 /notify、/line、/stock 這三個 skill」，Claude 會重新建立。

### 第四步：確認 GitHub Actions 仍在運作

以下兩個排程完全在雲端執行，換電腦**不影響**，無需任何操作：

| 排程 | Repo | 狀態確認 |
|------|------|---------|
| 股價通知 | yaojing277/stock-notify | [Actions 頁面](https://github.com/yaojing277/stock-notify/actions) |
| YouTube 通知 | yaojing277/stock-notify | [Actions 頁面](https://github.com/yaojing277/stock-notify/actions) |

---

## 定期維護建議

每次新增或修改設定後，執行以下指令同步到 dotfiles：

```bash
# 告訴 Claude Code：
幫我更新 dotfiles
```

Claude 會自動把最新的 `.zshrc` 和 Skills 同步到 `yaojing277/dotfiles`。

---

## 快速確認清單

換電腦後，確認以下項目都正常：

- [ ] `source ~/.zshrc` 執行無錯誤
- [ ] `echo $LINE_TOKEN` 有輸出值
- [ ] `/notify 測試` 能收到 LINE 訊息
- [ ] GitHub Actions 股價通知仍在排程中
- [ ] GitHub Actions YouTube 通知仍在排程中
