### launchd 每日觸發（2026-10-08 起）

排程的**主要觸發源在本機**，換電腦後不重裝就只剩 GitHub cron 備援（會晚 5～8 小時、偶爾整天不跑）：

```bash
mkdir -p ~/Library/LaunchAgents "$HOME/Library/Application Support/wealth-sync"
cp jimmy_scripts/trigger_wealth_sync.sh "$HOME/Library/Application Support/wealth-sync/"
chmod +x "$HOME/Library/Application Support/wealth-sync/trigger_wealth_sync.sh"
cp jimmy_scripts/com.jimmy.wealthsync.plist ~/Library/LaunchAgents/
launchctl bootout  gui/$(id -u)/com.jimmy.wealthsync 2>/dev/null
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.jimmy.wealthsync.plist
```

⚠ **腳本必須放在 `~/Library/Application Support/`，不能指向 `~/Downloads`**
——launchd 受 macOS TCC 限制讀不到那裡（`Operation not permitted`）。
plist 裡的路徑含使用者名稱，換帳號要改。

⚠ 接電源時系統才不會睡眠（本機 `pmset` AC 為 `sleep 0`、電池為 1 分鐘）；
Mac 睡著時 launchd 會在喚醒後補跑，**關機則不會**。

## 還原步驟

### 第一步：安裝必要工具

```bash
# 安裝 Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安裝 Python
brew install python

# 安裝 Claude Code
npm install -g @anthropic-ai/claude-code
```

### 第二步：還原環境變數（.zshrc）

```bash
# clone dotfiles
git clone https://github.com/yaojing277/dotfiles.git ~/dotfiles

# 複製到家目錄
cp ~/dotfiles/.zshrc ~/.zshrc

# 讓設定生效
source ~/.zshrc
```

### 第三步：還原 Claude Code Skills

```bash
# 建立資料夾
mkdir -p ~/.claude/commands

# 從 dotfiles 複製（若已備份）
cp ~/dotfiles/commands/*.md ~/.claude/commands/
```

> 若 Skills 未備份到 dotfiles，告訴 Claude Code「幫我重建 /notify、/line、/stock 這三個 skill」，Claude 會重新建立。

### 第四步：確認 GitHub Actions 仍在運作

以下兩個排程完全在雲端執行，換電腦**不影響**，無需任何操作：

| 排程 | Repo | 狀態確認 |
|------|------|---------|
| 股價通知 | yaojing277/stock-notify | [Actions 頁面](https://github.com/yaojing277/stock-notify/actions) |
| YouTube 通知 | yaojing277/stock-notify | [Actions 頁面](https://github.com/yaojing277/stock-notify/actions) |
