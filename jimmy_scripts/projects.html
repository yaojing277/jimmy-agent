YouTube 影片 AI 摘要
貼網址 / 頻道自動監控 → AI 重點摘要 · v2.0
Python Claude CLI youtube-transcript-api GitHub Pages
貼上 YouTube 網址，自動抓字幕（zh-TW 人工字幕優先、退到自動字幕， 無字幕自動 Whisper 語音轉錄）→ claude CLI 產生結構化摘要 → 深色 HTML 摘要頁：一句話總結、重點清單、可點跳轉的時間戳章節、金句與適合誰看。 另可 yt_auto_summary.py 一鍵檢查三個頻道新片、自動摘要＋部署＋LINE 推播。
項目說明
單片摘要python3 yt_summary.py <網址>
新片自動摘要python3 yt_auto_summary.py
監控頻道阿良的正二人生 / 槓桿人生 / 卡哇KAWA
AI 引擎claude CLI（訂閱制，免 API key）＋ faster-whisper 轉錄
摘要庫yt_summaries/index.html
  • 網址解析、字幕語言優先序、無字幕 Whisper 轉錄 fallback
  • 時間戳章節跳轉連結、同片重跑覆蓋防呆
  • claude CLI 登入並實測成功（TED、阿格力 EP134）
  • 摘要庫部署 GitHub Pages（deploy_yt_summaries.sh 一鍵）
  • 頻道新片自動摘要（yt_auto_summary.py：RSS 比對已見清單 → 摘要 → 部署 → LINE）
  • 本機設定 LINE 金鑰（line_secrets.json）啟用摘要推播
