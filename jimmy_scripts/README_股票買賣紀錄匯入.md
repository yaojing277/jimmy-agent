## 處理規則(已建立的慣例)

**記入**(目前只填三欄:股票 + 日期 + 淨額):
- 集買(買進)→ 日期填 **F 買進日**,金額填 **P 應收付**
- 集賣(賣出)→ 日期填 **J 賣出日**,金額填 **P 應收付**

**排除**(非股票買賣):
- 證券信託款、借貸月扣款、基金配息、收益分配、IPO 申購扣款/退款

**標的**:一律轉**股票代號**,純數字代號(0050/0056/00878…)前面加單引號 `'` 以**文字格式**寫入,避免前導零被吃掉(否則 `0056` 會變成 `56`)。

**重點:交割日 vs 成交日**——對帳單是「交割日(T+2)」,分頁是「成交日」。
淨額(對帳單金額)= 賣出成本 − 手續費 − 交易稅。若擔心重複,可用淨額回比分頁的 `M−N−O`。

## 下次怎麼新增(兩種方式)

### 方式 A:交給 Claude(最省事)
1. 把券商交割明細**擷圖**貼給 Claude,說「**新增股票買賣紀錄**」。
2. Claude 會辨識 → 分類(集買/集賣/排除)→ 代號對應 → 更新 `sheets_writer.py` 的 `ROWS` → 執行寫入 → 回報結果。
3. (已做成 skill,Claude 會自動依循這套規則。)

### 方式 B:自己手動
1. 編輯 `sheets_writer.py` 最上方的 `ROWS`(用 `_buy(代號,日期,淨額)` / `_sell(代號,日期,淨額)`,**由新到舊**排列)。
2. **確認 `PRE_FIX = []`**(除非要順手修某格)。
3. 先看分頁結構(可選):`python3 sheets_writer.py inspect`
4. 寫入:`python3 sheets_writer.py write` → 看預覽 → 輸入 `yes`。
   - 它會在第 4 列上方插入 N 列再寫入,**不會覆蓋**舊資料。

## 疑難排解

| 症狀 | 原因 / 解法 |
|------|------|
| `0056` 變成 `56` | 純數字代號要前置 `'`(文字格式) |
| 在終端輸入 `yes` 沒反應 | 改用管道:`printf 'yes\n' \| python3 sheets_writer.py write` |
| 跑出 `redirect_uri_mismatch` / `access_blocked` | OAuth 同意畫面要把自己加入「測試使用者」 |
| 想還原 | 寫入前先在 Google Sheets「檔案 → 建立副本」備份;或手動刪掉多插的列 |
| `PRE_FIX` 忘了清空 | 會誤改既有單格!每批新資料前確認 `PRE_FIX = []` |
